# CRVPINN for time-dependent pollution propagation

This repository contains the source code accompanying the manuscript:

**"Collocation-based Robust Physics Informed Neural Networks for
time-dependent simulations of pollution propagation under thermal
inversion conditions on Spitsbergen"**

## Contents

- `manufactured_sm1.py`  
  Main manufactured-solution benchmark used to verify the PINN and
  CRVPINN formulations for the transient advection-diffusion problem.

- `manufactured_sm2.py`  
  Additional manufactured-solution benchmark used for convergence and
  collocation-grid studies.

- `pollution_propagation_snowmobiles.py`  
  CRVPINN simulation of pollution propagation generated by moving
  snowmobiles under thermal inversion conditions.

## Requirements

- Python 3
- PyTorch
- NumPy
- Matplotlib
- imageio

Install the required Python packages with:

    pip install -r requirements.txt

## Computational experiments

The manufactured-solution experiments compare PINN and CRVPINN
training and evaluate the relation between the loss function and the
true approximation error.

The snowmobile-pollution example implements the time-dependent
advection-diffusion model with a moving pollution source and the
robust CRVPINN loss based on the Gram matrix.

## Reproducibility

Random seeds and the principal numerical parameters are specified
directly in the source files.

The codes were developed and tested using Python and PyTorch.
GPU execution is automatically selected when CUDA is available.
